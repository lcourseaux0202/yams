# Jeu du Yams

Projet universitaire où deux joueurs s'affrontent au jeu du Yams dans le terminal et peuvent visualiser le récapitulatif de leur partie sur un site web.

> [!NOTE]  
> L'API utilisée pour enregistrer et récupérer les parties n'étant plus accessible, la visualisation des parties sur le site est impossible...

## Installation

```bash
git clone https://github.com/lcourseaux0202/yams
cd yams
mcs main.cs
mono main.exe
```

Une fois la partie terminée, un récapitulatif au format JSON sera généré.
